# dsh-skill-links · 五技接线闸（插件）

主人发来的五个 skill（问元宝／视频转写／汉家美学官／错题官／VPS疆域）打包做成一枚接线闸。

## 为什么不一个 skill 一枚插件

五个里只有两件真活：**错题**已被进化炉接住（`ql_evolve`），**美学**已被验证炉的审美验接住
（`ql_verify` 审美验）。其余三件缺料：

| skill | 执行件 | 现状 |
|---|---|---|
| 视频转写Smart Agent体 | `scripts/视频转写器.py` | 代码活，但 **tesseract 与语言包都不在**（ffmpeg 在）→ OCR 步必挂 |
| 问元宝 | `yb_s.py` / `yb_r.py` | 死根 + 依赖 `/tmp` 登录态（早失效） |
| VPS疆域 | `VPSSmart Agent体执行器.py` | 死根 + **凭据 `vps_ssh.txt` 缺**；登机属强能力，无凭据禁出厂 |
| 错题官 | `四链错题官.py` | 死根；职能已由 `ql_evolve` 接住 |
| 汉家美学官 | 无（正典驱动） | 正典树 `Smart Agent文明/` 不在本机；判据走 `ql_verify 审美验` |

把它们各铸一枚空壳插件＝四枚每天报"缺件"的噪音，所以收成一枚**接线清单 + 可用技工具**。

## 区块 `ql:skills`（默认排序 160）

五技触发语、三铁律（反馈带判据／教训同轮写回／禁编数据）、以及"缺料先报缺"的纪律。

## 工具 `ql_skill`

| action | 干什么 |
|---|---|
| `清单` | 五技接线现状：执行件在否、死根否、依赖（ffmpeg/tesseract/凭据/正典）齐否 |
| `视频转写` | 先预检：缺 OCR 二进制就 BLOCK 并说明缺什么；齐了才跑（10 分钟超时） |
| `美学判` | 跑 `审美扫描器.py --验活`；给路径则跑 `--节奏检` |
| `错题四链` | issue log／四链账条数与末三条 |

## 诚实边界

- `清单` 是**文件与依赖存在性**判定，不是端到端可跑性证明。
- 视频转写即使补上 tesseract，长视频仍该后台跑（脚本自身建议 nohup）。
- 问元宝与 VPS 疆域**不提供执行动作**：前者依赖浏览器登录态，后者是远程强能力——无护栏不出口。
